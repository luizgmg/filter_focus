qgisMinimumVersion=3.22
description=Filter multiple layers by the selected feature of a reference layer and zoom to it.
about=Filter Focus turns a set of related layers into a sequential navigation. Pick a reference layer and a relationship field, choose the target layers (each with its own matching field), and every time you select one or more features in the reference layer the plugin applies a subset filter to all targets and centers the map on the selection. A built-in panel lets you step through features (Previous/Next, searchable list) and shows the attributes you choose. Original layer filters are preserved and restored when you stop. Optionally exports a local Shapefile copy of the reference layer so it can be filtered too.
